## 状态说明

- **待评审**：交付物和测试已完成，等待责任人或跨模块评审。
- **进行中**：已有负责人，正在实现。
- **待开始**：全部前置依赖已满足，可以安排执行。
- **阻塞**：至少一个前置依赖尚未满足，或受阶段门禁限制。
- **完成**：已通过 `tasks.md` 的 Definition of Done 和对应阶段门禁。

本表不替代 [`tasks.md`](../tasks.md) 中的交付物、验收口径与优先级定义。任务范围、依赖或验收口径发生变化时，应先更新 `tasks.md`，再同步本表。

## 更新规则

1. 本表状态只反映当前执行进度，任务优先级、交付物和验收口径仍以 [`tasks.md`](../tasks.md) 为准。
2. 任务进入待评审后，应记录评审人；评审通过后改为完成，并同步检查直接后继任务是否可转为待开始。
3. 阻塞任务只记录直接未满足的前置；依赖链中的间接阻塞通过前置任务继续追踪。
4. 每次状态变化同时更新顶部统计；阶段门禁变化时更新对应阶段的全部任务状态。
